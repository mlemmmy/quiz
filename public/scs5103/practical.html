QUESTION 01 · IMAGE CLASSIFICATION

Classify 10,000 labelled images belonging to five classes using k-NN, SVM and a CNN. Preprocess the images and evaluate accuracy, precision, recall, F1-score and confusion matrices.

Answer / procedure:

  1. Split the labelled images into training and test sets, then resize all images to a common size.
  2. Normalize pixel values, for example to the range 0–1, so that features are on a consistent scale.
  3. Train three classifiers: k-Nearest Neighbors (k-NN), Support Vector Machine (SVM), and a Convolutional Neural Network (CNN).
  4. For k-NN and SVM, represent each image as a feature vector. For a CNN, retain the image structure and learn features through convolutional layers.
  5. Predict the classes of the test images and construct a confusion matrix for each classifier.
  6. Calculate accuracy, precision, recall and F1-score. For multiple classes, report macro/weighted averages where appropriate.

Key formulas: Accuracy = correct predictions / total predictions. Precision = TP/(TP+FP). Recall = TP/(TP+FN). F1 = 2(Precision×Recall)/(Precision+Recall).

Conclusion: compare the three classifiers using the measured results rather than assuming one is best. Discuss errors visible in the confusion matrices and possible causes such as similar-looking classes, noise or insufficient training data.

Marks: preprocessing 5; classifier implementation 10; evaluation metrics and confusion matrices 10.

QUESTION 02 · IMAGE SEGMENTATION

Segment a medical image containing possible tumours using Otsu's method and k-means clustering. Visualize and compare the outputs using Dice or Jaccard, then discuss challenges and improvements.

Answer / procedure:

  1. Load and preprocess the MRI image, keeping the image dimensions and intensity information consistent.
  2. Apply Otsu's thresholding to automatically choose an intensity threshold separating foreground and background.
  3. Apply k-means clustering to group pixel intensities/features into clusters; select the cluster corresponding to the suspected tumour region.
  4. Display the original image beside both segmentation masks so the results can be visually inspected.
  5. Compare each segmentation against the available ground-truth mask using Dice coefficient or Jaccard index.

Dice: 2|A∩B|/(|A|+|B|). Jaccard: |A∩B|/|A∪B|. Higher values indicate greater overlap with the reference segmentation.

Challenges: medical images can contain noise, intensity variation, weak tumour boundaries, artefacts and tissues with similar intensities. Improvements can include denoising, contrast enhancement, better feature selection, morphological post-processing and more appropriate clustering/segmentation models.

Marks: segmentation implementation 10; visualization/comparison 10; challenges and improvements 5.

QUESTION 03 · FEATURE EXTRACTION & DIMENSIONALITY REDUCTION

For grayscale handwritten-digit images, extract features using PCA and HOG, reduce the dimensions to two principal components, visualize the result and discuss classification trade-offs.

Answer / procedure:

  1. Flatten each grayscale image into a feature vector when preparing the data for PCA.
  2. Apply Principal Component Analysis (PCA) to transform the original variables into principal components ordered by explained variance.
  3. Keep the first two principal components and plot the samples on a 2-D scatter plot, using different markers/labels for digit classes.
  4. Compute Histogram of Oriented Gradients (HOG) features to describe local edge directions and shape structure.
  5. Use the extracted features as inputs to a classifier and compare classification performance, computational cost and dimensionality.

Interpretation: PCA is a dimensionality-reduction technique that preserves directions of high variance, while HOG is a shape/edge descriptor. PCA can greatly reduce the number of variables, but information useful for class separation may not always correspond to the highest variance. HOG can retain useful shape information but introduces feature-design and parameter choices.

QUESTION 04 · OBJECT DETECTION

Detect and localize household objects using a pre-trained CNN-based detector such as YOLO, SSD or Faster R-CNN. Fine-tune it with transfer learning and evaluate using mAP.

Answer / procedure:

  1. Prepare the household-object dataset with images and corresponding object annotations/bounding boxes.
  2. Select a pre-trained detector such as YOLO, SSD or Faster R-CNN.
  3. Replace/adapt the detection head for the required object classes and fine-tune the network using transfer learning.
  4. Run the trained detector on unseen test images and obtain predicted classes, confidence scores and bounding boxes.
  5. Evaluate detection performance using mean Average Precision (mAP) and inspect predictions visually.
  6. Show sample images with bounding boxes and labels to demonstrate correct detections and common errors.

Interpretation: a useful evaluation should discuss both numerical performance and localization quality. Errors can include missed objects, false detections, poor localization and confusion between similar household items.

Marks: object-detection implementation 10; fine-tuning/performance evaluation 10; visualization 5.

QUESTION 05 · IMAGE RESTORATION

Restore images corrupted by Gaussian noise using a Wiener filter and Non-Local Means denoising. Compare visual quality, PSNR and SSIM, then discuss parameter optimization.

Answer / procedure:

  1. Load the clean/reference images and their Gaussian-noise versions, where available.
  2. Apply a Wiener filter to estimate the underlying image while accounting for noise and local signal characteristics.
  3. Apply Non-Local Means (NLM), which denoises a pixel using similar patches found across the image rather than relying only on immediate neighbours.
  4. Compare the restored images visually for sharpness, texture preservation and remaining noise.
  5. Calculate PSNR and SSIM against the clean reference. Higher values generally indicate closer agreement with the reference for these metrics.
  6. Repeat with sensible parameter settings and select settings based on validation results, balancing noise removal against loss of detail.

Parameter discussion: filter strength, estimated noise level, search-window size and patch size can affect the restoration result. Over-aggressive denoising may remove useful detail, while weak settings may leave visible noise.
